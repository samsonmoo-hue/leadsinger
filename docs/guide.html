領唱提示回到首頁

使用說明

領唱操作，樂手跟隨。所有人選擇同一個房間，就能同步看到歌名與演奏提示。

領唱：建立房間與歌單

  1. 首頁點「領唱建立房間」。房間名稱自動產生，可按「換一個」，再按「建立房間，確認詩歌」。
  2. 輸入歌名，按「增加一首歌」。用拖曳把手或上下箭頭調整順序。
  3. 速度可留空；需要節拍提示時，在歌曲旁的「速度（選填）」輸入 BPM。
  4. 按「確認並進入房間」儲存歌單，將房間名稱告訴樂手。

樂手：加入並觀看提示

  1. 首頁選擇領唱告知的房間，身分選「樂手」，按「進入房間」。
  2. 等待領唱操作，歌名與亮起的提示會自動更新，不必重新加入。

已有房間的領唱，也可從首頁選擇房間與「領唱」身分，繼續管理歌單。

♥ 速度與紅心

BPM 是每分鐘拍數，可填 1–300 的整數。60 BPM 每秒跳一次，120 BPM 每半秒跳一次。

填寫後，歌名右側會出現跳動紅心；留空則不顯示。要修改或清除速度，請由領唱點「詩歌確認」，修改後再按「確認並進入房間」。

紅心是無聲的視覺節拍提示；各裝置速度相同，但不保證同時落在同一拍點。

使用小提醒

螢幕長亮：進房後自動嘗試啟用，請查看畫面底部狀態。使用時保持網頁在前景；若啟用失敗，可按「重新啟用」或調整手機省電、自動鎖定設定。

離開與刪除：「離開房間」只離開畫面，房間仍保留。領唱在「詩歌確認」刪除房間，會清除整份歌單，所有團員回到房間列表。

看不到新功能：重新整理網頁，再選擇房間與身分加入。
